> 2026-08-06:仓库内 M1 实现候选与自动化门禁已完成,等待独立 PR Agent 审核。下列发布验收项保持未勾选,其中真人首次使用、实体设备触控、正式平台矩阵、安装容器与未来真实 schema 迁移不能由当前自动化代签。

## North Star(本里程碑一句话目标)

让首次使用 Desktop Pull 的个人用户无需教程,在桌面或手机界面上快速整理、拖拽并安全恢复一组本地任务。

## In Scope(范围内)

- 通过全局收件箱入口或分类上下文入口只输入标题快速创建任务,创建后再查看、补充可选备注和编辑属性;未提交草稿按 D-099 跨响应式形态和备份精确恢复入口、代次、原文与 UTF-16 光标。
- 未完成/已完成状态与分类内已完成折叠区。
- `P0` 至 `P5` 单值优先级,新增默认 `P3`。
- 固定收件箱、单归属自定义分类及 D-100 约束的草稿感知分类删除行为。
- 纵向分类清单中的组内与跨组直接拖拽。
- 当前设备持久化、区分任务与分类主体并使用 D-101 七字段公共外壳、D-102 的 14 值精确事件闭集、D-103 的事件专属最小严格详情、D-104 经 D-105 修订的内容变化精确分支、D-105 的完成/重新打开精确详情、D-106 / FORMAT-021 的历史任务邻居联合、D-107 / FORMAT-022 的创建初始分类与创建后嵌套位置详情、D-108 / FORMAT-023 的优先级发生时分类与旧新值详情、D-109 / FORMAT-024 的组内排序发生时分类、状态与移动前后位置详情、D-110 / FORMAT-025 的跨分类状态、来源移除前与目标插入后详情、D-111 / FORMAT-026 的分类删除派生迁移状态、来源整批前位置与最终收件箱位置、D-112 / FORMAT-027 的软删除时分类、状态与移出前位置、D-113 / FORMAT-028 的恢复后实际分类、状态与插入后位置、D-114 / FORMAT-029 的分类创建严格空详情和稳定逻辑键的全局历史、垃圾箱单任务恢复与 30 天永久清理;清理目标在其他记录中的结构化任务引用同步去身份化。
- D-115 / FORMAT-030 的分类重命名精确 `{ beforeName }` 详情:改名后名称只由公共 `subject.name` 承担,旧名与新名保留用户原文且不同,当前状态与唯一历史事件原子提交,同名提交无操作。
- D-116 / FORMAT-031 的分类排序精确 `{ beforePosition, afterPosition }` 详情:公共主体保存被移动 Custom 分类发生时 ID / 名称,两侧只保存 Custom 序列的严格前后邻居或 `start` / `end` 边界,Inbox 永不成为邻居;真实换位只原子改变 `categoryOrder` 并追加唯一分类事件,放回原位无操作。
- D-117 / FORMAT-032 的分类删除精确 `{ affectedTaskCount }` 详情:公共主体保存被删 Custom 分类发生时 ID / 名称,计数冻结删除受理时实际迁入 Inbox 的活动任务总数,空分类为 `0`,不含垃圾箱、逻辑到期残留、历史引用或草稿;正常生产与 FORMAT-026 `eventOrder = 1..N` 原子对应,任务永久清理后分类事件和原计数不变。十个任务事件与四个分类事件共 14 个详情分支已经全部锁定;14 值闭集与八个动作组不变。
- 完整本地备份的手动导出与导入。
- 数据已加载后的正式任务、分类或历史业务写入故障保持日常操作可用,并提供待保存状态、自动重试和应急完整备份;维护事务使用各自故障规则。
- 应用更新只迁移不可写候选数据库代次;迁移或候选启动失败时清理候选并自动回退到可离线完整使用的旧数据库与 last-known-good 应用版本。
- 同一存储作用域只允许一个活动窗口加载和操作数据;其他实例不展示数据,只支持在没有待保存状态或敏感事务时无损移交控制权。
- 普通网页与可安装 PWA 中桌面、移动端的同构离线核心路径。
- D-118 的 M1 客户端实现基线:React 构建响应式界面,应用源码逻辑使用 TypeScript,Vite 生成纯客户端 SPA,既定顶层页面导航使用 React Router;生产核心路径只依赖静态应用资源、浏览器能力与既定 Service Worker。
- D-119 的顶层 Hash 路由:五个规范页面地址相对于应用部署基址可见,同会话浏览器后退/前进可用,新文档启动与未知 Hash 以 `replace` 归一化到任务清单顶部,Manifest 从任务 Hash 启动且静态托管不依赖 History API 重写。
- 以滚动版本窗口正式覆盖 Windows 11、macOS、iOS/iPadOS 与 Android 的既定网页和安装矩阵;网页始终为基础入口,安装失败不阻断网页使用。
- 不同浏览器、用户配置文件或隔离安装容器各自保有本地数据库;共享同一 `IndexedDB` 时执行单活动窗口,跨作用域通过完整备份迁移。
- 完整的简体中文与英文界面,以及运行中的产品内语言切换。
- 默认任务入口、桌面侧边导航与移动端三标签导航,设置和备份保持低频可达。

## Non-goal(本里程碑明确不做)

- 不做团队协作、登录、云端备份或跨设备同步。
- 不做截止日期、提醒、重复任务、子任务或附件。
- 不做多分类、标签或整份清单历史回滚。
- 不做原生移动 App;本里程碑只交付移动端适配的第一版界面,不加入 Capacitor、iOS / Android 原生工程、原生桥接、设备权限或为未来容器预建的持久化适配层。
- 不把 Windows 10、Linux、ChromeOS、内嵌或应用内浏览器、隐私模式、预发布浏览器、Android 厂商浏览器及滚动窗口外版本纳入正式发布 Gate。

## 首个实现任务包

`TP-M1-01` 只交付默认中文任务页上的 Inbox 连续快速创建、创建历史、草稿、IndexedDB 刷新恢复以及创建相关可写降级。完成后用户必须能执行“输入 A → 提交 A → 输入框清空并保持焦点 → 输入 B”,并在刷新后看到两条任务;持久化失败不得锁住输入或假报成功。

本包不实现任务编辑、优先级调整、完成状态、自定义分类、拖拽、垃圾箱、历史页面、普通备份导入导出、Service Worker/PWA 安装离线或英文切换,也不暴露对应死入口。它不会使完整 G1-F1、G5-F9 或 G6 变为完成。
