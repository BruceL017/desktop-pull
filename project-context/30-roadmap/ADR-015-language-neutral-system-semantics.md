# ADR-015 · 系统语义与界面语言分离

## Status

Accepted

## Date

2026-07-29

Amended 2026-07-30 by D-097

## Decision Drivers

- M1 必须在同一份本地数据上运行时切换简体中文与英文,不能靠改写历史或重新导入数据完成。
- 历史只追加且备份必须长期兼容;把当前语言文案保存为状态或事件值会让旧事实混用语言或需要破坏性迁移。
- 用户输入的任务、备注和自定义分类本身可能包含任意语言,产品不能把用户事实误当作待翻译界面资源。

## Context

既有历史契约要求保存分类发生时显示名称,其中固定收件箱若直接保存“收件箱”,英文时间线会混入中文;若切换后改写为 `Inbox`,又会违反历史不可改写。任务状态、事件类型、动作组和位置边界存在同样风险。备份若依赖导出时语言,还会让同一业务快照在不同界面语言下产生不同数据语义。

## Decision

- 固定系统分类、任务状态、精确事件类型、位置边界和 D-097 的通用不可用任务引用必须以稳定、语言无关的语义码持久化;动作组必须从精确事件类型唯一映射,不得重复保存本地化分组文案。界面按当前语言把系统语义呈现为简体中文或英文文案。不可用值不得保存被清理任务的原文标题。
- 固定收件箱的任务归属与历史引用只保存稳定系统身份,不保存“收件箱”、`Inbox` 或其他本地化名称快照。切换语言后,既有事件中的收件箱按当前语言呈现,事件本身不改写。
- 用户输入的任务标题、备注、自定义分类名称及其历史发生时快照必须保留原文,不得自动翻译、生成多语言副本或随界面语言回写。
- 完整备份保存语言无关系统语义与用户原文。导出时界面语言不得改变业务数据;同一备份在任一受支持语言下导入后必须恢复相同事实。
- 其他契约中的中文按钮、状态、动作和位置文本默认是简体中文资源或命令语义示例,不是持久化枚举值。英文界面必须从相同语义生成对应英文。
- 简体中文与英文资源都属于 PWA 离线核心资源;首次成功加载后不得依赖网络下载另一种语言才能切换。
- 收件箱双语保留名称规则由 D-086 锁定,首次语言匹配与默认简体中文由 D-087 锁定,设备语言偏好的即时生效、持久化与备份边界由 D-088 锁定,设置中的切换入口由 D-089 锁定。

## Consequences

- 切换语言后,历史中的动作、系统分类、状态和位置摘要会使用新语言,但用户输入及其事件发生时快照保持原文。
- 数据库与备份 schema 必须区分系统语义码和用户原文,不能用一个任意显示字符串同时承载两者。
- 新增界面语言不要求迁移既有任务或重写历史,但必须为全部既有系统语义提供完整资源。
- 测试必须比较语言切换前后的业务数据不变性,并在离线状态验证两种语言资源可用。

## Rejected Alternatives

- **把当前语言的系统文案直接保存到状态、历史或备份**:会让切换后的界面混用旧语言,并使备份语义依赖导出语言。
- **切换语言时批量重写旧历史与备份内系统文案**:破坏历史只追加与备份原子性,故障中断还会形成半迁移数据。
- **自动翻译用户标题、备注或自定义分类快照**:会篡改用户事实,也无法可靠判断中英混合内容是否需要翻译。
