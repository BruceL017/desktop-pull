# 产品标识(Product Identity)

## 名称

- 产品英文名:`Desktop Pull`
- GitHub 仓库名:`desktop-pull`

## 命名约定

对外展示使用 `Desktop Pull`;GitHub 仓库使用对应的小写连字符形式 `desktop-pull`。

## 界面语言

- M1 同时提供简体中文与英文界面,并允许用户在运行中的产品内切换。
- `Desktop Pull` 是两种语言共用的产品名,不翻译、不随界面语言变化。
- 语言切换只改变呈现层:产品自有系统概念由稳定语义码按当前语言显示;用户输入的任务、分类或备注及其历史快照保持原文,业务历史事实不得重写。
