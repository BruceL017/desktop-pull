# 任务清单布局契约(Task List Layout Contract)

## 强制规则

### LAYOUT-001 · 纵向分类分组

主任务页必须把收件箱和每个自定义分类呈现为纵向排列的独立分组。不得把分类实现为需要横向滚动的看板列。

### LAYOUT-002 · 分组可折叠

每个分类分组必须能独立展开和折叠。折叠只改变显示状态,不得改变任务内容、分类归属或持久手动顺序。

### LAYOUT-003 · 组内与跨组拖拽

用户必须能在分类分组内拖拽任务到精确插入标记表示的位置,也必须能把任务拖到另一分类中匹配当前完成状态的指定位置。跨组有效放下后,任务只能属于目标分类且完成状态保持不变;取消或无效放下不得改变分类、状态或顺序。落点、空或折叠目标和边缘滚动遵守 `drag-interaction.md`。

### LAYOUT-004 · 响应式同构

桌面与移动视口必须使用相同的纵向分类层级和任务关系。响应式变化不得把移动端降级为缺失分类、拖拽或折叠能力的独立简化产品。

### LAYOUT-005 · 已完成区域

每个分类必须默认展开未完成任务,并在该分类底部提供默认折叠的“已完成”区域。该区域只能按任务状态投影视图,不得改写任务分类或持久手动顺序。拖拽只能在同完成状态序列间移动任务,不得把跨越“已完成”边界解释为状态切换。

### LAYOUT-006 · 分类顺序

收件箱必须固定为第一个分类分组。自定义分类必须按用户最后一次成功拖拽后的持久顺序纵向显示;分类排序不得改变分组中的任务归属或任务顺序。

### LAYOUT-007 · 备注预览保持清单密度

有备注的任务必须在标题下方显示最多一行弱化预览,无备注任务不得为预览预留空间。备注长度和换行不得让主清单展示完整备注或产生不受限的任务行高度。

### LAYOUT-008 · 标题高度与横向约束

任务标题在桌面和移动视口中最多占两行,超出部分省略。普通文本和连续超长字符都必须限制在任务行可用宽度内,不得造成任务行控件移位、遮挡或页面横向滚动。

### LAYOUT-009 · 会话内保留折叠与滚动状态

按 `navigation.md` 在当前应用会话内离开并返回任务页时,任务清单必须恢复滚动位置、分类折叠状态和“已完成”区域折叠状态。恢复浏览状态不得自动恢复任务编辑器焦点或移动端键盘。

### LAYOUT-010 · 跨重启保留折叠偏好

分类及其“已完成”区域的用户折叠选择必须在当前设备跨刷新和应用重开保持。滚动位置只在当前会话内恢复;新会话必须从任务清单顶部开始。

成功执行完整备份覆盖导入属于折叠偏好的重置边界:导入分类首次显示时全部展开,“已完成”区域全部折叠。未成功导入不得重置当前偏好。

### LAYOUT-011 · 被恢复任务按需定位

从垃圾箱恢复反馈选择“查看任务”后,任务清单必须按 `navigation.md` 展开目标任务所在分类和必要的“已完成”区域,将完整任务行滚动到视口可见范围并给予短暂高亮。高亮只表达本次定位,不得修改任务数据、追加历史或持续占用任务行布局;定位不得打开编辑器或输入界面。

### LAYOUT-012 · 选择器移动任务按需定位

从任务行移动反馈选择“查看任务”后,任务清单必须复用 LAYOUT-011 的展开、滚动和短暂高亮规则。未选择该操作时,源任务行消失不得改变当前滚动锚点或自动滚动到目标分类。定位高亮不得修改任务、顺序或历史。

## 验收 Gate

- 收件箱与多个自定义分类在主页面纵向排列,页面无需横向滚动才能访问其他分类。
- 分别折叠任一分类后,其他分类保持原显示状态;重新展开后任务数据与顺序不变。
- 任务可以在同一分类内拖到目标位置,刷新后顺序保持。
- 任务可以跨分类拖到目标位置,刷新后只出现在目标分类的对应位置。
- 在移动视口中仍能访问全部分类,并完成分组折叠、组内拖拽和跨组拖拽。
- 标记任务完成后,任务出现在原分类的已完成区域;重新设为未完成后,任务按未改变的持久顺序重新出现在原分类活动清单。
- 调整多个自定义分类的顺序并刷新或重启应用,验证顺序保持、收件箱仍位于第一位,且各分类任务内容和顺序不变。
- 在桌面和移动视口中检查长备注任务,验证预览始终限制为一行且清单没有横向溢出;无备注任务没有空白预览行。
- 在桌面和移动视口中检查两行以上及连续超长字符标题,验证最多显示两行、控件位置稳定且页面无横向溢出。
- 在同一会话内切换任务、历史和垃圾箱,验证返回任务页后滚动及两级折叠状态恢复,编辑器和键盘不自动出现。
- 调整两级折叠状态后刷新和重开应用,验证折叠选择保持但滚动回到任务清单顶部。
- 成功覆盖导入后验证折叠状态恢复默认值;取消或失败的导入不改变当前折叠状态。
- 分别查看恢复后的未完成和已完成任务,验证正确区域展开、完整任务行可见并短暂高亮,清单没有布局跳动、编辑器或键盘弹出,且任务数据与历史没有额外变化。
- 从任务行选择器移动未完成和已完成任务,验证默认保持当前滚动位置;主动查看后正确状态区展开并定位高亮,且没有额外数据或历史变化。
- 在同分类和跨分类拖拽未完成及已完成任务,验证精确落点只位于匹配状态序列,有效放下保持状态,无效放下恢复原位置。
- 向空或折叠分类拖入任务,验证无需预先点击即可临时展开并显示完整宽度落点;取消恢复折叠,成功后当前会话可见且持久折叠偏好不被自动改写。
